连接信息

默认模板：火山引擎（API 网关 + VeFaaS + VMP）。需要已部署兼容的个人用量服务，普通推理 Endpoint 不具备用量查询能力。

统计周期

可同时添加今日、本周、本月；每个周期可单独设置 Credit 预算，留空只统计用量。

多周期用于 Gateway Usage v1。其他协议的额度周期由接口响应决定，不会凭空生成周期余额。

更换端点 / 字段映射 / 私有服务

同协议可换地址和凭证；异协议需更换模板或字段映射。没有用量 API 时需先在提供商侧部署认证和聚合服务。路径拼接到 Base URL，不自动删除 /v1。

映射使用 JSON Pointer，例如 /data/balance。timeFormat：iso / unix-seconds / unix-ms。resetsAt 是恢复时间，expiresAt 是到期时间。不得在请求体中填写密钥。
